Personal Portfolio Website

A responsive website to showcase my professional profile

Project Overview

This personal portfolio website was created to showcase my professional profile, technical skills, academic projects and contact information in a clean and user-friendly design.

Objective

The main objective is to create a professional online presence where recruiters and visitors can easily learn about my skills, projects and background.

Key Features

  • Professional Home page
  • About Me section
  • Technical Skills section
  • Projects / Portfolio section
  • Individual project details pages
  • Responsive design for different screen sizes
  • Interactive navigation and buttons

Technologies Used

HTML5 CSS3 JavaScript Boxicons

Responsive Design

The website is designed to adapt to desktop, tablet and mobile screen sizes using responsive CSS techniques and media queries.

Future Improvements

Future improvements can include adding GitHub repositories, live project demonstrations, a working contact form, additional projects and further visual improvements.
