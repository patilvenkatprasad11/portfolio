PROJECT DETAILS

Deep Autoencoder for Secure IoT Device Classification

With Data Authentication

Project Overview

This project focuses on secure IoT device classification and data authentication. It uses machine learning and deep learning techniques to improve device identification and security in IoT environments.

The proposed approach uses an Autoencoder for feature extraction and a Random Forest classifier for device classification.

Objective

The main objective is to develop an intelligent system capable of classifying IoT devices while improving security and supporting authenticated data exchange.

Methodology

  • Data preprocessing and exploratory data analysis
  • Feature extraction using a Deep Autoencoder
  • Device classification using Random Forest
  • Model training and evaluation
  • Authentication and security mechanisms

Technologies Used

Python TensorFlow Keras Scikit-learn NumPy Pandas Matplotlib Seaborn Jupyter Notebook

Machine Learning Models

The project report describes the use of Logistic Regression, K-Nearest Neighbors (KNN), Autoencoder and Random Forest approaches for classification and evaluation.

Security & Authentication

The system incorporates authentication as part of the IoT security approach. The project is designed to support trusted device identification and secure handling of IoT data.

Results

The project report presents classification experiments and evaluation results for the proposed approach. The reported results include an accuracy of 91.70% for the AE-Boosted Forest Logistic evaluation.

Future Scope

The project can be further developed toward scalable IoT environments, improved device classification, stronger authentication and deployment-oriented security solutions.
